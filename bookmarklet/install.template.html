Copy for Claude

A bookmark button. Open any eBay or Etsy page, tap it, and the listings on screen are copied as tidy text. Paste that into Claude and ask your question. It runs in your own browser, so there are no bot-checks and no API keys.

Install the button

Copy for Claude

Drag this tag onto your bookmarks bar.
No bar? Press Ctrl+Shift+B (⌘+Shift+B on a Mac).

If dragging doesn't work, make a new bookmark called Copy for Claude and paste the code from the box below as its address.

  1. Tap Copy code below.
  2. In Safari, bookmark any page: tap Share, then Add Bookmark, and name it Copy for Claude.
  3. Open Bookmarks, tap Edit, then tap the new bookmark.
  4. Clear the address and paste the code. Tap Done.
  5. To use it: on an eBay or Etsy page, open Bookmarks and tap Copy for Claude.
  1. Tap Copy code below.
  2. In Chrome, bookmark any page (⋮ menu, then ☆), then tap Edit.
  3. Rename it Copy for Claude, clear the URL and paste the code. Save.
  4. To use it: on an eBay or Etsy page, tap the address bar and type Copy for Claude, then tap the bookmark that appears. Chrome on Android won't run it from the bookmarks list, only from the address bar.

Use it

  1. Open a search or a listing. Use filters on the site as normal (price, condition, "Sold items" for real selling prices).
  2. Tap Copy for Claude. A small panel confirms what was copied. If it says to copy manually, tap Copy in the panel.
  3. Paste into your Claude chat with your question, for example "Which of these is the best deal?" or "Is this seller trustworthy?"
